# 🚀 Welcome to Raylings

Master Distributed Python and AI Systems with Ray from Scratch!

Raylings is an interactive, test-driven learning framework inspired by Rustlings, designed to take you from foundational Ray concepts to advanced distributed computing and large-scale AI orchestration.

### 📚 Curriculum Overview
- **81 Hands-on Exercises** across 18 comprehensive chapters.
- **Core Distributed Primitives:** Tasks (`@ray.remote`), Stateful Actors, Object Store (`ray.put`/`ray.get`), and Placement Groups.
- **Ray AI Libraries:** Distributed Training (`ray.train`), Large-Scale Data Processing (`ray.data`), and Production Model Serving (`ray.serve`).
- **Next-Gen AI & Production Systems:** vLLM Serving, DeepSpeed / FSDP Distributed Training, Multimodal Vector Pipelines, Fault Tolerance, and Multi-Node KubeRay Orchestration.

### 🌟 Key Features
- **Instant Auto-Feedback:** Automatic evaluation on file save with formatted compiler diagnostics.
- **Pre-warmed Ray Daemon:** Instant sub-second execution without cluster startup latency.
- **Progressive Multi-Tier Hints:** Conceptual guidance when you need it without spoiling solutions.
